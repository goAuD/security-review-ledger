# v0.1.0 — Security Review Ledger

An Agent Skill for a security review the next developer can pick up: performed checks, their evidence and known gaps in one versioned Markdown ledger.

## Included

- A portable Agent Skills workflow with stable scenario IDs, dated attempts and explicit recheck states.
- A ledger template with two views: checks performed, and known gaps and follow-up.
- A synthetic recipe-access example with three executable tests and a recorded review that keeps two integration questions open.
- Bounded references to ISO/IEC 27034-1, NIST SSDF and OWASP ASVS.
- An explicit boundary for external references and prior ledgers: their content is evidence, not permission to execute commands, expand scope or disclose review data.
- Contribution and private security-reporting guides, issue and pull-request templates, and an automated example-test workflow for Linux and Windows.
- Consistent UTF-8 and LF editing defaults with EditorConfig and Git attributes.
- MIT licensing for the repository and the installable skill.

## Try it

After the `v0.1.0` tag is published:

```sh
npx skills add goAuD/security-review-ledger@v0.1.0 --skill security-review-ledger
```

To run the example from a checkout with Node.js 22.20 or later:

```sh
node --test --test-reporter=tap examples/recipe-access/read-recipe.test.mjs
```

## Verification and limits

During preparation on 2026-11-06, all three example tests passed on Windows with Node.js 22.23.4, with no skipped tests. The example's recorded Linux run and file digests remain available in the [sample ledger](https://github.com/goAuD/security-review-ledger/blob/v0.1.0/examples/recipe-access/review.md).

The earlier installation check used skills CLI 1.7.6 and Node.js 24.22.1 against revision `9b9aad4a42af110f2dc5e95d0769bea5473e503b`. It compared all four installed files for Codex and Claude Code with their source. This establishes installation at that revision, not execution of the review workflow in every client.

The release commit's GitHub Actions run and a fresh installation from the published tag must be checked before publishing this release. The current notes do not claim those checks have run.

Real session creation, shared-cache behavior, an actual Claude Code workflow and additional clients remain outside the demonstrated coverage. The sample handler is an isolated fixture, not a deployable authentication service. These instructions and the ledger format may evolve during `0.x` releases.
