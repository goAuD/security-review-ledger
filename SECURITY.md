# Security policy

This repository contains an Agent Skill and synthetic example code. Security reports here should concern its instructions, bundled files or examples, such as behavior that could expose private review data or cause an agent to exceed the agreed scope.

## Report a concern privately

Use [GitHub private vulnerability reporting](https://github.com/goAuD/security-review-ledger/security/advisories/new) for a suspected vulnerability in this project. Do not disclose an unresolved vulnerability in a public issue or pull request.

Include the affected tag or commit, relevant file, expected and observed behavior, impact, and the smallest reproduction using synthetic data. Never submit credentials, customer data or private application reports.

Ordinary documentation improvements and non-sensitive bugs can use [GitHub issues](https://github.com/goAuD/security-review-ledger/issues/new/choose).

## Scope and maintenance

Report vulnerabilities found in another project while using this skill to that project's maintainers through their security reporting process. This repository is not a place to publish third-party security findings.

Security fixes are developed on `main` and included in the next release. Older releases do not have separate maintenance branches. Include the affected revision even when you cannot reproduce the concern on the latest version.
